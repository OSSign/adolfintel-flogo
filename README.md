# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [adolfintel/flogo](https://github.com/adolfintel/flogo/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [adolfintel/flogo](https://github.com/adolfintel/flogo).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/adolfintel-flogo/actions).
